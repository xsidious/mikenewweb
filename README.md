# ASAP — Precision Detailing (Next.js)

Cinematic entrance: **damage → polish → brand-new reveal**, then wipe into the product site.

## Run

```bash
cd web
npm install
npm run dev
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000).

## Storyboard

1. Studio splash + spotlights + **ENTER**
2. **Surface Damage** — rusty / worn paint footage
3. **Swirl Marks** — defect visualization
4. **Correction** — live polishing buffer footage
5. **Precision Polish** — compound / macro work
6. Kinetic **ASAP** type beat
7. **Factory Finish** — polished car reveal
8. Wipe into homepage (or **SKIP INTRO**)

## Stack

- Next.js (App Router) + TypeScript + Tailwind
- GSAP timelines
- Video assets in `public/videos/` (Pexels live clips + generated cinematic plates)
